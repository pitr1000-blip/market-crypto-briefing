마켓 · 크립토 브리핑 — 배포용 PWA 패키지
================================
이 폴더는 미국 증시 · 가상화폐 데일리 브리핑 PWA "마켓 · 크립토 브리핑"의 소스예요.
(index.html, manifest.json, sw.js, icons/ 4개 파일 세트, og-image.png)

배포 현황 (2026.08.27 기준)
----------------------------
- 실제 서비스 주소: https://market-crypto-briefing.vercel.app/
- 이 GitHub 저장소(pitr1000-blip/market-crypto-briefing)가 Vercel 프로젝트와
  Git 연동되어 있어요. main 브랜치에 커밋을 push하면 Vercel이 자동으로
  감지해서 몇 초~몇 분 안에 새 버전을 배포해요.
- 원래 매일 아침 PDF로 만들어 카카오톡으로 보내던 "미증시 및 가상화폐
  briefing"을 이 웹 대시보드로 완전히 대체했어요. PDF+카카오톡 발송은
  더 이상 쓰지 않아요.

수정하는 방법
--------------
- 급하게 한 군데만 고칠 때: GitHub 저장소에서 해당 파일(예: index.html)을
  열어 연필(✏️) 아이콘으로 바로 편집 → "Commit changes"로 main에 커밋
  → Vercel이 알아서 재배포
- 통째로 갈아끼울 때: 해당 파일을 "Add file" → "Upload files"로 다시
  업로드해도 됩니다

매일 아침 데이터 자동 갱신
--------------------------
- Code 루틴 "미증시·가상화폐 브리핑 자동 배포 (GitHub push)"가 매일 아침
  7시에 자동 실행돼요. 미국 증시(다우/나스닥/S&P500/러셀2000, 섹터,
  등락 상위, 채권/유가/달러/금, 연준, 오늘 일정)와 가상화폐(BTC/ETH/
  SOL/XRP 가격, ETF 자금 흐름, 미결제약정/펀딩레이트/청산 규모, BTC
  지지·저항선, 이슈 심층분석)를 새로 조회해서 index.html의 데이터
  부분만 갈아끼우고 main에 push해요. 레이아웃·CSS·JS 로직은 건드리지
  않아요.
- "실행 성공" 표시만으로는 실제로 데이터가 바뀌었는지 알 수 없어요 —
  확인하려면 GitHub의 커밋 로그와 Vercel의 Deployments 탭을 같이
  확인하세요.

서비스워커(오프라인 캐시) 주의
--------------------------------
- sw.js는 HTML 페이지(navigate 요청)는 네트워크 우선, 아이콘 같은
  정적 자산만 캐시 우선으로 만들어져 있어요. 이래야 매일 브라우저를
  다시 열 때 어제 데이터에 갇히지 않아요. sw.js를 손댈 일이 있으면
  이 전략을 절대 "캐시 우선"으로 바꾸지 마세요 — am-briefing-pwa에서
  실제로 이 문제를 겪고 고쳤어요.

홈 화면에 앱처럼 설치하기
--------------------------
- Android(Chrome): 메뉴 → "홈 화면에 추가"
- iOS(Safari): 공유 버튼 → "홈 화면에 추가"
누르면 아이콘이 생기고 앱처럼 전체 화면으로 실행돼요.

카카오톡/슬랙 등에 링크 공유 시 미리보기 카드
----------------------------------------------
- index.html <head>에 og:title / og:description / og:image(og-image.png,
  1200x630, 다크 증권사 톤) 태그가 들어있어요. 배포된 주소를 카톡·슬랙·
  트위터 등에 붙여넣으면 "마켓 · 크립토 브리핑" 소개 카드가 자동으로
  떠요.
- og:image, twitter:image, og:url은 실제 배포 주소
  (https://market-crypto-briefing.vercel.app/) 기준 절대경로로 이미
  넣어뒀어요. 도메인을 나중에 바꾸면 이 3곳도 같이 바꿔주세요.
- 카톡 공유 미리보기가 바로 안 뜨면, 카카오 디버거
  (https://developers.kakao.com/tool/debugger/sharing) 에 배포 주소를
  넣고 "초기화" 하면 캐시가 갱신돼요.
